Before you do this, please do note that you should have basic working knowledge of Linux and Containerisation. You don't need to be an expert, but you should be comfortable with both. Things go wrong and break. You will need to understand how to analyse logs and action what the logs are telling you. You'll spot examples of this in the 'Troubleshooting' section of the guide. They're issues that I have experienced and resolved in my own deployment and I suspect more issues will appear over the years.


This repo isn't something that can be deployed via ArgoCD, it's a manual process but if you follow it, it will assist you in setting up your own cluster. As things change or I spot/learn new things, I will add them. Good luck :)
